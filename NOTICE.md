# AcadPulse notice

AcadPulse is a development application for academic record management and descriptive analytics. Verify institutional rules and the software's behavior before using it for official academic decisions.

The prior `Student-analysis-system-` repository is used as a functional, UI and calculation reference. The legacy calculation source is preserved and documented for compatibility; this is not a statement that the code is a currently approved university regulation.

This ZIP contains no database with student records and no private secret. Generate a new local `SECRET_KEY`, keep `.env` private, and do not commit real student data or uploaded documents.
